# 金鳳出航｜一顆鳳梨的遠行

以臺灣鳳梨外銷與冷鏈保鮮為主題的互動式故事網站，透過自然捲動串連果園、跨海運輸、果心褐化、七站冷鏈及永續發展。

## 功能

- 鳳梨線框顯影載入開場，可略過或重播。
- 隨捲動推進的故事、航線及技術圖解。
- 七站冷鏈流程與預冷氣流演示。
- 桌面、平板及手機的響應式排版。
- 系統減少動態效果支援與訪談影片視窗。

## 專案檔案

- `index.html`：網站內容、圖解與開場結構。
- `style.css`：版面、響應式樣式與動畫。
- `app.js`：捲動敘事、載入流程及影片互動。
- `assets/`：網站圖片與字型。
- `FONT-LICENSE.txt`：第三方字型授權資訊，請保留。

## 本機預覽

本專案使用 HTML、CSS 與 JavaScript，不需要安裝 npm 套件或進行建置。

在此資料夾開啟終端機，執行：

```bash
python -m http.server 8080
```

接著開啟 `http://localhost:8080`。Windows 也可將 `python` 改為 `py`。亦可使用編輯器的靜態網頁預覽功能。

## 上傳 GitHub

將這個資料夾內的檔案與 `assets` 資料夾上傳至儲存庫根目錄，使 `index.html` 位於根目錄。整個專案可部署於 GitHub Pages 或其他靜態網頁主機。

## 資料與素材

網站內保留農業研究及延伸閱讀來源。技術圖解與航線為教學示意，實務作業應依經驗證的 SOP 執行。外部訪談影片播放需要網路連線。
